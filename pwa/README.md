# PWA · тестовая интеграция локального ИИ

Приложение стартует без личного словаря. Каждый загружает свой Excel A English / B русский / C IPA. Готовая версия — `dist-pwa/`; локальный WebLLM включён в сборку, веса модели не включены.

Сборка: установить ai-engine зависимости через pnpm с lockfile, `node ai-engine/build.mjs`, `node build.mjs`, `node build-pwa.mjs`. Для ПК — `node build-desktop.mjs`. На Windows сборщик может требовать доступ вне песочницы для чтения каталогов пакетов.

Размещать dist-pwa по HTTPS, например GitHub Pages; поддержан префикс `/repo/`. Локальные тесты используют HTTP localhost. Двойной щелчок по index.html не устанавливает PWA. Сайт ещё не опубликован.

Внизу страницы — «Проверка с ИИ»: диагностика, Qwen 2.5 1.5B (0.5B не прошла проверку качества и доступна только для удаления старого кеша), явная загрузка, прогресс, остановка, удаление выбранного кеша. После перезапуска модель нужно открыть снова; сохранённые файлы берутся из кеша. Оболочка около 12 МБ, модель скачивается отдельно и существенно больше.

Неизвестный перевод в режиме ввода проверяется после словаря и опечаток. Любой новый перевод подтверждается человеком, даже при положительной рекомендации. Сохранённые варианты затем принимаются автоматически по словарю. Новый синоним сохраняется отдельно только по действию пользователя. Смена страницы/направления/словаря/режима отменяет устаревший запрос.

Обновление оболочки предлагается кнопкой. Service worker удаляет только старые technowords-shell-*, сохраняя словари и модельные кеши. Веса не обновляются в фоне. Для переноса из старого HTML загрузить JSON-копию: file://, localhost и HTTPS имеют разные хранилища. Синхронизации между устройствами нет.

Проверены в Vivaldi: оболочка без сети, обновления и сохранность данных, реальный bundle без самовольной загрузки модели, сценарии с подставленными ответами ИИ, исключение/возврат слов, экспорт, мобильная ширина. Настоящая Qwen 2.5 1.5B проверена на Intel Gen12LP в Vivaldi, включая полностью закрытый и заново запущенный браузер без сети, отмену генерации и удаление выбранного кеша без потери словаря и другой модели. 13 из 15 тестовых вердиктов совпали с ожиданием; два неверных ответа были ошибочно приняты. Поэтому ИИ даёт рекомендацию с подтверждением. Это маленький набор примеров, а не гарантия качества. Физические Samsung/iPhone и GPU OOM/device loss ещё не проверены. См. AI-VALIDATION.md.
