# Технословарь

Личный тренажёр английского: свой Excel, ввод ответа или четыре варианта, EN ↔ RU, повторение ошибок и сохранение прогресса.

## Открыть приложение

**[Технословарь — сайт / PWA](https://dizzy061.github.io/techwords/)**

На Android открой сайт в браузере и установи приложение через его меню установки. На iPhone открой в Safari: «Поделиться» → «На экран Домой». После подготовки приложения можно учить слова без сети.

## Скачать для ПК

- **[ПК с необязательным локальным ИИ — ZIP](https://dizzy061.github.io/techwords/downloads/TechnoWords-PC.zip)**: распакуй всю папку и запусти `Start-TechnoWords.cmd`. Оставь окно запуска открытым.
- **[Один HTML без ИИ — ZIP](https://dizzy061.github.io/techwords/downloads/TechnoWords-HTML.zip)**: распакуй один файл и открой в браузере.

## Свой словарь

В Excel: A — английский, B — русский, C — IPA (необязательно). Поддерживаются XLSX, XLSM, CSV и TSV. Несколько переводов разделяй `;`: одного варианта достаточно. Встроенного личного словаря нет; каждый импортирует собственный файл.

Слова и прогресс хранятся в браузере на устройстве. Для переноса между телефоном, ПК, прежним HTML и сайтом используй «Резервная копия» → JSON. Автоматической синхронизации между устройствами нет.

## Обучение

Ошибки и опечатки возвращаются через 20–30 других вопросов. Закрепление — три верных ответа подряд без опечаток. «Уже знаю» исключает слово из тренировок в обоих направлениях; вернуть его можно в словаре. После верного ответа доступен ручной переход и отключаемый автопереход через 1,5 секунды.

## Локальный ИИ

CMD открывает приложение. Для ИИ дополнительно нажми «Подключить ИИ» → «Загрузить / открыть модель». Первая загрузка Qwen 2.5 1.5B требует интернета и свободного места; затем файлы берутся из кеша, а вычисления выполняются на устройстве.

ИИ даёт рекомендацию для переводов вне словаря; новые ответы подтверждает человек. Сохрани удачный перевод — затем он принимается сразу по словарю. Пока модель не готова, неизвестный ввод ждёт решения пользователя.

Модель проверена в Vivaldi на Windows, включая полный перезапуск без сети. Физические Samsung/iPhone и ограничения их памяти ещё требуют проверки. Наличие WebGPU само по себе не гарантирует запуск. Подробности: [AI-VALIDATION.md](AI-VALIDATION.md).

## Обновления

PWA предлагает применить новую версию по кнопке, сохраняя словарь и независимый кеш модели. Большие веса модели не скачиваются и не обновляются вместе с интерфейсом автоматически.

Репозиторий содержит исходники и автоматическую сборку сайта. Лицензии библиотек находятся в `WEBLLM-LICENSE.txt` и встроены в HTML.

## Разработка и обновления

В репозитории находятся исходники. На машине разработчика:

```text
npm ci
npm test
npm run build
```

`build-site.mjs` собирает сайт и скачиваемые файлы в `dist-pwa/`. GitHub Actions делает ту же сборку при изменении `main` и публикует результат. В Settings → Pages должен быть выбран источник **GitHub Actions**. Локальные `dist-*`, `node_modules` и веса модели в Git добавлять не нужно.
