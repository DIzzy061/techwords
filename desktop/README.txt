ТЕХНОСЛОВАРЬ ДЛЯ ПК · ТЕСТОВАЯ ВЕРСИЯ ИИ

1. Распакуй всю папку. Запусти Start-TechnoWords.cmd.
2. Откроется HTML в браузере по адресу http://localhost:8787/.
3. Оставь окно запуска открытым. Для остановки нажми Ctrl+C или закрой окно.
4. Импортируй свой Excel: A английский, B русский, C транскрипция (необязательно).
5. Кнопка «Проверка с ИИ» внизу: проверь устройство и нажми «Загрузить / открыть модель».
   Первая загрузка требует интернета и свободного места; затем проверь работу без сети.
   Модель открывается заново после перезапуска страницы, скачанные файлы берутся из кеша.

CMD запускает приложение, но не открывает модель автоматически. Её состояние видно над вводом
ответа, рядом есть «Подключить ИИ». Если модели нет и ответ не найден в Excel, приложение
предлагает оценку вручную, открыть ИИ или исправить ответ; ошибка без твоего решения не пишется.

Android Studio, Node.js и Python для этого запуска не нужны. Используется PowerShell Windows.
Обычная тренировка доступна и при открытии HTML двойным щелчком, но для ИИ нужен запуск выше.
Прогресс по file:// и http://localhost:8787/ хранится отдельно. Для переноса скачай JSON-копию
в старой странице и загрузи её в новой. При повторных запусках используй тот же адрес и браузер.

ИИ рекомендует оценку для неизвестного перевода. Любой новый ответ нужно подтвердить.
Можно сохранить удачный перевод — затем он принимается сразу, без ИИ.
Qwen 2.5 1.5B проверена на ПК с Intel GPU, в том числе после перезапуска браузера без сети.
Модель может ошибаться: подтверждение не убирается. На Samsung/iPhone нужна отдельная проверка.
Новый перевод сохраняется отдельно по твоему действию; его можно удалить в «Словаре».
Экспорт «HTML с прогрессом» сохраняет слова и статистику, ИИ в один файл не упаковывается.
Кеш модели не включается в резервную копию. Словарь каждого пользователя личный.
